# Hydrogen-Fuel-Cell-Anomaly-Research

## ABSTRACT
Hydrogen fuel is a critical technology for sustainable energy solutions, particularly in long-duration space missions and carbon-free projects. The U.S. commercial energy produced from hydrogen is projected to increase in hydrogen energy literature. The leading causes of this energy shift are reductions in the cost of electrolyzer manufacturing and increased efficiency of electrolyzers. To encourage the use of hydrogen energy and improve the dependability of hydrogen fuel cells, this study investigates anomaly detection performance using unsupervised and supervised machine learning techniques. Isolation Forest, One-Class Support Vector Machine (SVM), and Local Outlier Factor (LOF) algorithms are used for unsupervised machine learning; Logistic Regression, Support Vector Machine (Linear), Support Vector Machine (Radial Basis Function), Decision Tree, Random Forest, and K-Nearest Neighbor are used for supervised machine learning. These analysis techniques use a time-series dataset of a 20% random selection of 185,721 data points (37,144 data points in total) from four NASA hydrogen fuel cells. This data encompasses ambient temperatures, measured currents and voltages, load currents and voltages, capacities, and measured temperatures through various charging and discharging cycles. Principal Component Analysis (PCA) plots are used to highlight data clusters and outliers for both unsupervised and supervised learning models to compare anomalous data. Key findings reveal a generally dissimilar detection pattern across the three unsupervised algorithms, with only a 15.07% overlap of the three unsupervised models in specific anomaly indices. These indices indicate a “true positive” anomaly, or an anomaly most likely to be detected correctly (0.754% of the total data). It is determined, based on F1-score weighting for the three unsupervised machine learning models, that 1,296 anomalies are detected from the 37,144 data points (3.49% of the total data). These F1-score weighted anomalies are then applied as truth values for the supervised machine learning models. The role of the supervised models is primarily to validate the anomalies identified by the unsupervised models as well as to determine the most important features of the hydrogen fuel cells when deciding where anomalies occur. These variables are determined to be power difference (derived), capacity (given), load power (derived), load current (given), measured power (derived), and load resistance (derived). These six variables make up for 99.7% of all detected anomalies in the data set.  The ability to accurately predict and reduce fuel cell anomalies ensures improved efficiency and reduced dependability on traditional energy sources, thus promoting advancements of revolutionary and environmentally friendly technologies across diverse applications.
### Keywords: Hydrogen Fuel Cells, Anomaly Detection, Unsupervised Machine Learning, Supervised Machine Learning, Time-Series Data, F1-Score, Feature Importance, Validation
